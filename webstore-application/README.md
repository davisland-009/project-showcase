Within the client and server directories are the resources to build a generic webstore application. The client side uses React and routes for different views, the database uses postgreSQL, the Spring Boot framework handles requests in Java, with JDBC performing the CRUD operations in the database. Render hosts the database and the server. Netlify hosts the React frontend.

Pardon the graphic design elements, the artwork was all originally mocked up in MS Paint and simply serves as a general idea for a webstore.

From the homepage, the user can browse products in two different layouts; tile view and table view. The user can choose to examine a product closer in a product details view. If the user wishes to save items to a cart, they will have to register and login. Logging in allows the user to save their cart between sessions. In the cart view, the user will see their saved items and the subtotal/tax/total of their entire cart. Items may be deleted from the cart as well. If the browser is storing the user's login token, the application will check memory first and keep the user logged in if their token hasn't expired.

Since this is a mock application for the purpose of showcasing full stack projects, I will likely clear the database every 30 days or so. The user may have to re-register if that time has elapsed.
